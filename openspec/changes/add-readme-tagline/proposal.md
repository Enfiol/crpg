## Why

The README's top-level title (`# cRPG`) is immediately followed by a blank line, so a reader scanning the top of the file has no instant, scannable summary of what the project is. A short tagline directly under the title gives newcomers a one-glance description before they read the fuller paragraph.

## What Changes

- Insert a single tagline line in `README.md` immediately under the `# cRPG` title, describing the project as a persistent multiplayer mod for Mount & Blade II: Bannerlord.
- Touch only `README.md`. No other files, and no structural or formatting changes to the existing README content.
